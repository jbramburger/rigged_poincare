# The Spectral Skeleton of Chaos: Koopman Wave Packets on Poincaré Sections

This repository contains the MATLAB implementations accompanying **The Spectral Skeleton of Chaos: Koopman Wave Packets on Poincaré Sections**. The examples use measure-preserving extended dynamic mode decomposition (mpEDMD) and **rigged Dynamic Mode Decomposition (riggedDMD)** to extract macroscopic organization from chaotic dynamics.

The central idea is that finite regularized Koopman wave packets provide two complementary views of a dynamical system:

- their **phase** acts as a finite-resolution transport coordinate, revealing coherent regions and approximate cyclic motion;
- their **modulus** identifies a low-modulus skeleton near which this phase description becomes poorly resolved.

Together, these quantities expose coarse symbolic dynamics, organize unstable periodic orbits, and describe macroscopic transport on Poincaré sections.

The examples range from a one-dimensional chaotic map to Poincaré maps generated by low- and high-dimensional continuous-time systems. Although the governing equations are known, the Koopman analyses use only sampled trajectories or section crossings and do not require closed-form expressions for the corresponding return maps.

## Main examples

The repository contains five primary examples and one supplementary example.

### Logistic map — `logistic.m`

- Applies EDMD, mpEDMD, and riggedDMD to the logistic map.
- Compares delay-coordinate dictionaries with \(d=11\) and \(d=51\).
- Computes spectral densities using separate smoothing parameters.
- Selects the finite mpEDMD mode nearest \(\lambda=-1\).
- Uses a wave packet centred at \(\theta=\pi\) to reveal an approximate two-region alternation.
- Computes kneading sequences and empirical transition frequencies.

### Rössler Poincaré map — `rossler.m`

- Generates event-located crossings of
  \[
  x=0,\qquad \dot{x}>0.
  \]
- Stores the resulting section data in `rossler_section_cache.mat`.
- Computes the scalar return map and invariant-coordinate histogram.
- Identifies an approximate fixed point and its nontrivial preimage.
- Uses riggedDMD to reveal a persistent spectral feature near \(2\pi/3\).
- Constructs a coarse three-region symbolic model and compares its predicted itineraries with observed periodic orbits.

### Kuramoto–Sivashinsky Poincaré map — `kuramoto_sivashinsky.m`

- Studies a 32-mode Galerkin truncation of the Kuramoto–Sivashinsky equation.
- Defines the Poincaré section
  \[
  a_2=0,\qquad \dot a_2>0.
  \]
- Uses event-located crossings generated by `ks_utils/generate_ks_section_data.m`.
- Computes uncentred principal-component coordinates for the section data.
- Removes the symmetry-induced component flip by studying the second-return map \(F=P^2\).
- Uses riggedDMD to uncover a macroscopic eight-region organization near \(\theta=\pi/4\).
- Connects the resulting transition graph with symbolic cycles and unstable periodic orbits.

### Forced Duffing oscillator, Regime I — `duffing_regime_I.m`

Parameters:
\[
\beta=1,\qquad
\delta=0.3,\qquad
\omega=1.2,\qquad
\gamma=0.5.
\]

The script:

- generates event-located stroboscopic section data;
- saves the data in `duffing_section_I_cache.mat`;
- identifies a dominant spectral component near \(2\pi/3\);
- constructs a three-region phase partition;
- measures the resulting predominantly cyclic transport;
- compares the phase and modulus with unstable periodic orbits of map periods one, two, and three.

### Forced Duffing oscillator, Regime II — `duffing_regime_II.m`

Parameters:
\[
\beta=0.25,\qquad
\delta=0.1,\qquad
\omega=2,\qquad
\gamma=2.5.
\]

The script:

- generates event-located stroboscopic section data;
- saves the data in `duffing_section_II_cache.mat`;
- identifies related spectral maxima near \(2\pi/7\), \(4\pi/7\), and \(6\pi/7\);
- constructs a seven-region phase partition using the dominant \(6\pi/7\) component;
- visualizes the one-step transport
  \[
  R_j\longmapsto R_{j+3}\pmod 7;
  \]
- tests robustness across several smoothing parameters;
- quantifies the concentration of transport errors near the low-modulus skeleton.

### Supplementary forced Van der Pol oscillator — `vanderpol.m`

- Studies a periodically forced Van der Pol oscillator using a stroboscopic Poincaré map.
- Computes a riggedDMD spectral density and wave packet near \(0.81\pi\).
- Examines phase-transport branches on the Poincaré section.
- Studies the return statistics and transition dynamics of low-modulus defect regions.
- Is included as a record of additional numerical tests but does not appear in the paper.
